# Declared DOCX main-document DrawingML references

This Knowledge adapter accepts one explicitly recovered original for a complete, pinned Registrar publication. It first runs the bounded [DOCX package-media inventory](docx-media-inventory-2026-10-02.md), then parses `word/document.xml` and `word/_rels/document.xml.rels` from the same original SHA-256. The receipt links the base media receipt digest and maps each syntactic `<a:blip>` inside `<w:drawing>` through a local `r:embed` image relationship to a verified `word/media/*` member SHA-256 and byte count. Repeated references remain separate; unreferenced media remains visible. Linked images, missing or external relationships, wrong types, absent media and blips without a relationship appear as explicit gaps. It does not fetch external targets.

The parser recognizes Transitional and Strict WordprocessingML, DrawingML and office relationship expanded namespace names. It requires a WordprocessingML `document` root and a package `Relationships` root with direct `Relationship` children. It refuses XML DTD/entity declarations, malformed XML, duplicate relationship IDs, unsafe internal relationship targets, more than 1 MiB per XML part, more than 256 DrawingML blips, more than 1,000 relationship entries, and more than 128 XML nesting levels. Only canonical raw relative package targets are accepted: percent-escaped, package-root, dot-segment, backslash and control-character targets deliberately refuse. The base adapter retains its 8 MiB original, 1,000 ZIP member, 32 MiB actual expansion, 256 media and CRC bounds. The fixed Python standard-library worker runs with `-I -S`, a 30-second timeout and a 1 MiB response bound.

Before publishing, the adapter rechecks the recovered original SHA-256 and byte count with a bounded stream, current source registration, pinned publication bytes, base media receipt, and its own module hash. The receipt contains only source/publication/original pins, a base receipt digest, reference indexes and relationship ID hashes, resolved member hashes/counts, gap labels and unreferenced member metadata. It retains no XML, alternate text, image bytes, external URL or recovered path. `coverage: declared-main-document-drawingml-only` describes syntax, **not** rendering or visual meaning. Headers, footers, VML, charts, other package parts, OCR and PDF images remain outside this receipt.

## Focused evidence

The actual Registrar fixture uses a `local-only` source, captures a DOCX, deletes the live file, explicitly recovers the pinned original, and checks duplicate mapped references, unreferenced media, unresolved/external/wrong-type/linked gaps, receipt redaction, deterministic replay, tamper refusal and disabled-registration refusal. It also tests unsafe traversal, wrong-type traversal, single-backslash and XML character-reference control targets against the public adapter; malformed XML/roots, DTD, duplicate IDs, NUL XML, oversized XML parts and reference overflow against the fixed worker. Verification counts and PR identity are recorded in the append-only overnight log after final checks.

This does not establish that Word displayed an image, the image's meaning, full DOCX visual coverage, Windows operation or production losslessness.
