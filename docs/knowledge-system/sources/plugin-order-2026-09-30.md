Received 2026-09-30 in the Temari conversation. The owner said: “I'm not sure
how much the lift is. it seems like we should create a fully working knowledge
system before we do the refactor. if so lets document this and continue trhe
build out”.

Interpretation: defer the proposed installable knowledge-plugin refactor until
Temari has a useful, measured knowledge workflow. Keep the future ability to
replace the model and source provider and to disconnect, uninstall and reinstall
the optional capability. This message authorizes continued build-out and asks
for the sequencing decision to be documented; it does not select a deployment
retention policy or authorize sending private source text to a hosted model.
