# NX05 milestone 1 invariant census

Premise under review: grouping the existing file stores behind a new interface makes their operations a shared control contract. The process tests refute this premise. The stores persist local state, but their public methods allow writes outside the proposed fenced publication path.

| Actor and write path                                                        | Required invariant                                                                                      | Observed at `18c3b16`                                                                                                                       | Milestone 1 decision                                                                                                       |
| --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Parent owner through `WorkflowRunStore.appendEvent`                         | Every event written while running must carry the current lease owner and token.                         | A former owner appended `stale-dispatch` after attempt 2 claimed the run.                                                                   | Fence running event appends in the file store. Do not expose raw append in the shared contract.                            |
| Parent owner through `WorkflowRunStore.transition`                          | A repeated key has the same complete command payload.                                                   | `{marker:"original"}` followed by `{}` returned the committed `SUCCEEDED` record.                                                           | Compare the complete supplied payload, including missing keys.                                                             |
| Child owner through `ChildTaskStore.complete`                               | A success result is published only after all referenced artifact bytes are present and hash valid.      | A `SUCCEEDED` record retained a portable reference whose bytes had never been written.                                                      | Keep the file adapter outside shared conformance. Require artifact validation as part of the shared publication operation. |
| Current runtime through `executeScheduledAndPersist` and `parallel-runtime` | Parent state, event, and dispatch intent commit together; child status and result commit under a fence. | Parent receipt save precedes run transition. Parallel workers call raw `childStore.complete`. Neither path implements the shared operation. | Leave shared integration blocked until callers move to a transactional provider. Keep the one engine.                      |
| File adapter and process fixture                                            | Recovery evidence applies to one host.                                                                  | Separate Node PIDs reopened the same directories; injected exceptions covered four commit stages per store.                                 | Preserve this evidence as single-host process recovery only.                                                               |

Rerun the path census with `rg -n 'appendEvent\(|transition\(|childStore\.complete\(' libs/runtime/src/lib --glob '!*.test.ts'`. Rerun the counterexamples with `pnpm nx run runtime:nx05-control-conformance --skipNxCache`. A passing process target establishes only the assertions it runs. It is not a shared-provider conformance verdict.
